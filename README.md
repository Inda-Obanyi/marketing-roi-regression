# Marketing ROI Analysis using Linear Regression

## Project Overview
This project analyzes the return on investment (ROI) of marketing campaigns using linear regression. The dataset contains information on advertising budgets across different channels (TV, Radio, Newspaper) and their corresponding sales figures. The analysis includes data exploration, model fitting, assumption checks, and business interpretation of results to provide actionable insights for optimizing marketing strategies.
The objective is to identigy the advertising channel with the highest ROI and provide recommendations for budget allocation to maximize sales.

## Dataset Features
- TV: Advertising budget for TV (in thousands of dollars)
- Radio: Advertising budget for Radio (in thousands of dollars)
Social Media: Advertising budget for Social Media (in thousands of dollars)
Sales: Sales figures (in thousands of units)

## Project workflow
1. Data Loading and Exploration: Load the dataset and perform initial exploration to understand the structure,data types, and summary statistics.
2. Data Visualization: Create visualizations such as correlation heatmaps and pairplots to identify relationships between variables.
3. Linear Regression Modeling: Fit a linear regression model using the best predictor variable (TV advertising budget) to predict sales.
4. Assumption Checks: Verify key regression assumptions (linearity, normality of residuals, homoscedasticity) through diagnostic plots.
5. Business Interpretation: Interpret the model coefficients, p-values, and R-squared to understand the impact of TV advertising on sales.
6. ROI Recommendation: Based on the model results, provide recommendations for optimizing the marketing budget allocation to maximize sales.
